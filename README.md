Расширение для поиска по вкладкам Chrome

Расширение для быстрого поиска и переключения между открытыми вкладками в Google Chrome. Позволяет искать по URL, заголовку и домену, включая кириллические домены.

✨ Возможности
🔍 Быстрый поиск по всем открытым вкладкам

🌐 Поддержка кириллицы - работает с русскими доменами и текстом

🏷️ Поиск по URL, заголовку и домену

⚡ Мгновенное переключение между вкладками

🎯 Удобный интерфейс с favicon и preview URL

🔒 Безопасность - не собирает данные пользователя

📦 Установка из исходного кода
Метод 1: Установка распакованного расширения
Скачайте исходный код

bash
git clone https://github.com/your-username/tab-search-extension.git
Или скачайте ZIP архив и распакуйте его

Откройте страницу расширений Chrome

В адресной строке введите: chrome://extensions/

Или перейдите через меню: ⋮ → Дополнительные инструменты → Расширения

Включите режим разработчика

В правом верхнем углу включите переключатель "Режим разработчика"

Загрузите расширение

Нажмите кнопку "Загрузить распакованное расширение"

Выберите папку с файлами расширения

Нажмите "Выбор папки"

Готово!

Расширение появится в списке и будет доступно через иконку в панели расширений

Метод 2: Перетаскивание папки
Распакуйте архив с расширением в удобную папку

Откройте chrome://extensions/

Включите "Режим разработчика"

Перетащите папку с расширением на страницу расширений

🚀 Использование
Откройте расширение

Нажмите на иконку расширения в правом верхнем углу Chrome

Введите поисковый запрос

Начните вводить текст в поле поиска

Поиск работает по:

Заголовку вкладки

URL адресу

Домену сайта

Переключитесь на вкладку

Кликните на нужный результат в списке

Расширение автоматически переключится на выбранную вкладку

📋 Требования
Google Chrome 109 или выше

Manifest V3 совместимость

🔧 Разработка
Сборка для публикации
Убедитесь, что все файлы находятся в одной папке

Создайте ZIP архив с содержимым папки

Загрузите на Chrome Web Store Developer Dashboard

Локальная разработка
Внесите изменения в файлы

На странице chrome://extensions/ нажмите кнопку обновления 🔄 на карточке расширения

🐛 Поиск и устранение неисправностей
Расширение не загружается:

Убедитесь, что все файлы присутствуют в папке

Проверьте, что manifest.json корректно оформлен

Включите "Режим разработчика"

Поиск не работает:

Проверьте, что есть открытые вкладки

Убедитесь, что вкладки не защищенные (chrome://)

Иконка не отображается:

Обновите расширение на странице chrome://extensions

Перезагрузите браузер
